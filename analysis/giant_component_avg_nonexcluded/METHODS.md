## Methods (giant-component group-average participation in percolation)

### Sample and adjacency averaging

Functional connectivity was summarized as a weighted adjacency matrix **PSI** (`psi_adj`) per participant (broadband MEG pipeline; same representation as used elsewhere in this project). Participants flagged for exclusion in the project quality-control table (`attack_outliers.csv`, column `excluded`) were removed. For each remaining participant, the upper-triangular weights were retained and the diagonal set to zero.

A **group-average adjacency** was computed as the elementwise mean of `psi_adj` over all included participants. No additional subject-wise z-scoring was applied in this leg beyond what is already embedded in the per-subject matrices.

### Giant-component–guided binarization (75% of nodes)

To obtain a single binary graph for the cohort, we applied a **giant-component size rule** adapted to the average matrix. Let \(n\) be the number of nodes. We defined a target giant-component order \(g = \mathrm{round}(0.75\,n)\). Across a uniform grid of \(10^3\) scalar thresholds spanning \([\min(\mathrm{avg\_psi\_adj}), \max(\mathrm{avg\_psi\_adj})]\), we formed a binary graph at each threshold by retaining edges with weight strictly above the threshold, measured the order of the largest connected component in the undirected graph, and selected the **largest (most permissive) threshold** for which that component still contained at least \(g\) nodes. The final analysis graph was the binary adjacency at that threshold. The procedure also records undirected graph density, the chosen threshold value, and the list of subject files that entered the average. Implementation: `make_avg_psi_giantcomp_nonexcluded.py` (default `gcc_fraction = 0.75`).

This binarization is **distinct** from retaining a fixed proportion (e.g. 5%) of the strongest edges; it ties sparsity to preserving a large connected backbone of the *average* network.

**Supplementary Figure S1** shows only this final binary `psi_adj` (grayscale: absent vs present edge), generated by `plot_figureS1_giant_binary_adjacency.py` for the supplement.

### Participation in percolation (PiP) on the group graph

Percolation attacks were simulated on the binary group graph using the same Monte Carlo engine as the thresholded per-subject analyses (`pip_converge_posthw5_thresh.m`). In brief, for each replicate attack, node removal order was drawn uniformly at random without replacement. After each removal, the order of the second-largest connected component in the surviving graph was recorded; the percolation step for that attack was defined as the step at which that order was maximized (standard PiP construction). Many independent attacks were accumulated in parallel (`parfor`) to estimate, at each attack depth, the probability that each node was removed **before** that depth.

**Proportional edge filter inside the MATLAB driver:** the driver can optionally keep only the strongest fraction of edges by magnitude before percolation. For this leg, **`THRESH_PROP = 1.0`**, which retains **all** off-diagonal edges present in the binary `psi_adj` after giant-component thresholding (no further sparsification in that step).

**Convergence:** sampling continued in chunks until Wilson 95% half-widths for the estimated participation curves stabilized according to built-in plateau criteria (window length, range, and slope tolerances; `REQUIRE_STABLE = 3` consecutive plateau checks). For this configuration, **`ENFORCE_HW95 = 0`**, so plateau detection did **not** require the mean half-width to fall below `HW95_TOL`; it used range-and-slope stability only (see `check_hw_plateau` in `pip_converge_posthw5_thresh.m`). The random seed was fixed via environment variables for reproducibility.

The converged trajectory was saved as `node_P` (attack step × node) in `*_ConvHW.mat`, together with count tensors and a `meta` struct documenting run parameters.

### Visualization of PiP trajectories

For publication-style surfaces, each `node_P` matrix was **time-weighted** so that earlier attack steps contribute more: with \(S\) steps and \(\tau = \max(2, S/6)\), displayed participation at step \(s\) was multiplied by \(\exp(-s/\tau)\) after setting non-finite values to zero and clipping negative values to zero (`plot_pip_surfaces.py`, `plot_tauS6_for_set`). This yields the `tauS6_postHW_giant_avg_nonexcluded` figures (2D heatmaps and 3D surfaces).

### Post hoc cluster labeling on the PiP matrix

Nodes were represented by their **cropped** PiP rows (each node’s participation across attack steps), multiplied by a **linear ramp** decaying from 1 at the first step to \(1/n_{\mathrm{steps}}\) at the last (`plot_avg_cluster.py`). **Ward** agglomerative clustering was fit on these node vectors in Euclidean space. For each candidate \(k \in \{2,\ldots,10\}\), cluster labels were obtained by cutting the tree for exactly \(k\) clusters (`scipy.cluster.hierarchy.fcluster`, `criterion='maxclust'`). The chosen \(k\) **maximized the mean silhouette coefficient** over nodes (custom silhouette on the pairwise Euclidean distance matrix). The **top cluster** for visualization was defined as the cluster with the largest mean summed feature weight across nodes. Brain marker plots used `nilearn.plotting.plot_markers` with MNI coordinates (`MNI_66_coords.txt`). Node indices from the top cluster were exported to CSV and joined with the AAL-based region list (`MNI_66_AAL_onelinestructure.csv`, `label_cluster_nodes.py`) for anatomical labels.

### Software and compute

Group averaging and plotting used **Python 3** with **SciPy** (MAT I/O, sparse graph routines). PiP convergence used **MATLAB R2024b** inside **Singularity** on a Slurm-managed cluster, with multi-core `parpool` sized to the allocated CPUs. Paths and resource requests are recorded in the Slurm shell scripts linked from `scripts/` in this bundle.
